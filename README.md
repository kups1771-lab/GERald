# Personal Portfolio – GitHub Pages

A responsive personal portfolio website built using:

- HTML5
- CSS3
- JavaScript

## Files

- `index.html` – main portfolio page
- `style.css` – website design and responsive layout
- `script.js` – mobile menu and dynamic year

## Before submitting

Replace these placeholders in `index.html`:

- `Your Name`
- `Your Course`
- `YN` (initials)
- GitHub repository links
- Live Demo links
- Project names/descriptions if needed

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under deployment source, choose the `main` branch and `/root` folder.
6. Save and wait for GitHub Pages to publish the website.
7. Open the generated GitHub Pages URL and test every link.

Do not use `#` for final project links. Replace them with real URLs before submitting.
